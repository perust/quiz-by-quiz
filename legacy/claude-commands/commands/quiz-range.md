quiz-challenge/src/data/questions.ts 파일에서 $1번부터 $2번까지의 문제를 검토합니다.

## 작업 순서

1. `quiz-challenge/src/data/questions.ts` 파일을 읽습니다.
2. id가 $1 이상 $2 이하인 문제만 추출합니다.
3. 해당 범위의 문제에 대해 아래 **세 가지 분석**을 수행합니다.

## 1. 문제 목록

범위 내 모든 문제를 아래 형식으로 출력합니다.

| # | ID | 카테고리 | 난이도 | 정답 번호 | 문제 |
|---|----|----------|--------|-----------|------|

## 2. 난이도 분포

범위 내 문제의 난이도 분포를 분석합니다.

| 난이도 | 문제 수 | 비율 | ID 목록 |
|--------|---------|------|---------|
| 쉬움   |         |      |         |
| 보통   |         |      |         |
| 어려움 |         |      |         |

### 난이도 균형 평가

- 권장 비율(쉬움 30% / 보통 40% / 어려움 30%)과 비교하여 편차를 분석합니다.
- 특정 난이도에 문제가 과도하게 쏠려 있으면 경고를 표시합니다.

## 3. 정답 분포

범위 내 문제의 정답 번호(0~3) 분포를 분석합니다.

| 정답 번호 | 보기 위치 | 문제 수 | 비율 | ID 목록 |
|-----------|-----------|---------|------|---------|
| 0         | 첫 번째   |         |      |         |
| 1         | 두 번째   |         |      |         |
| 2         | 세 번째   |         |      |         |
| 3         | 네 번째   |         |      |         |

### 정답 분포 평가

- 이상적 비율(각 25%)과 비교하여 편차를 분석합니다.
- 특정 번호에 정답이 50% 이상 집중되어 있으면 **경고**를 표시합니다.
- 한 번도 정답이 되지 않은 번호가 있으면 **주의**를 표시합니다.

## 4. 종합 의견

위 분석 결과를 바탕으로 다음을 종합적으로 평가합니다.

- 난이도 균형이 적절한지
- 정답 분포가 고르게 되어 있는지
- 개선이 필요한 경우 구체적인 조정 제안
