카테고리 "$1", 난이도 "$2"인 새 퀴즈 문제 1개를 생성하여 `quiz-challenge/src/data/questions.ts`에 추가합니다.

## 매개변수

- `$1`: 카테고리 — `한국사` | `과학` | `지리` | `예술과문화`
- `$2`: 난이도 — `easy` 또는 `쉬움` | `medium` 또는 `보통` | `hard` 또는 `어려움`

## 작업 순서

### 1. 사전 확인

1. `quiz-challenge/src/data/questions.ts` 파일을 읽습니다.
2. 카테고리가 `한국사`, `과학`, `지리`, `예술과문화` 중 하나인지 확인합니다. 아니면 중단하고 사용 가능한 카테고리를 안내합니다.
3. 난이도 매핑: `easy`/`쉬움`→`쉬움`, `medium`/`보통`→`보통`, `hard`/`어려움`→`어려움`으로 변환합니다. 이 여섯 값이 아니면 중단하고 사용 가능한 난이도를 안내합니다.
4. 현재 마지막 문제의 `id`를 확인하여 새 문제의 `id`를 결정합니다 (마지막 id + 1).

### 2. 현재 분포 분석

해당 카테고리 내에서 다음을 분석합니다:

- **난이도 분포**: 해당 카테고리의 쉬움/보통/어려움 비율 확인
- **정답 분포**: 전체 40문제의 정답 번호(0~3) 분포 확인
- **정답 번호 결정**: 전체 분포에서 가장 적은 정답 번호를 우선 배정

### 3. 문제 생성

아래 형식으로 문제 1개를 생성합니다:

```typescript
{
  id: <새 ID>,
  category: "$1",
  difficulty: "$2",
  question: "<문제>",
  options: ["<보기1>", "<보기2>", "<보기3>", "<보기4>"],
  answer: <0~3>,
  explanation: "<해설>"
}
```

### 4. 검증 가이드라인 (필수 준수)

생성한 문제가 아래 기준을 **모두** 충족하는지 반드시 확인합니다.

#### 4-1. 정답 유일성
- 정답이 하나뿐인지 확인합니다.
- 다른 해석이 가능하면 조건을 명시합니다 (예: "면적 기준", "2024년 기준").

#### 4-2. 최상급·단정 표현 검증
- 아래 표현이 포함된 경우 **측정 기준**을 반드시 명시합니다:
  - 가장, 최초, 최대, 최소, 최고, 최저, 최선, 최악
- 아래 단정 표현이 포함된 경우 **범위를 한정**합니다:
  - 유일한, 반드시, 절대, 항상, 모든
- 논란 가능한 내용은 "전통적으로", "중 하나" 등으로 완화합니다.

#### 4-3. 시간·범위 명확성
- 변할 수 있는 정보에는 시점을 명시합니다.
- 지리적·분류적 범위를 한정합니다.

#### 4-4. 사실 정확성
- 의심스러운 정보는 웹 검색으로 교차 검증합니다.
- 수치 데이터는 최신 공인 데이터를 사용합니다.

#### 4-5. 오답 보기 품질
- 오답 보기가 그럴듯하되, 명확히 틀린 것이어야 합니다.
- 정답과 혼동될 수 있는 함정 보기를 포함합니다.

### 5. 파일에 삽입

- 해당 카테고리의 마지막 문제 뒤에 새 문제를 삽입합니다.
- 기존 코드 스타일(들여쓰기, 쉼표 등)을 정확히 따릅니다.
