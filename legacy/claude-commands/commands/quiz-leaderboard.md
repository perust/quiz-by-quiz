`quiz-challenge`의 순위(리더보드) 시스템을 분석하고 관리합니다.

## 서브커맨드

- `$ARGUMENTS` 값에 따라 동작이 달라집니다:
  - (비어 있음) → **현재 시스템 분석** 실행
  - `review` → 코드 리뷰 및 개선 제안
  - `persist` → localStorage 영구 저장 기능 추가 제안
  - `export` → 데이터 내보내기 기능 추가 제안

## 2. 코드 리뷰 (`review`)

순위 시스템 관련 코드를 심층 리뷰합니다.

### 검토 항목

| 항목 | 파일 | 평가 | 설명 |
|------|------|------|------|

검토 항목:
- **타입 안전성**: LeaderboardEntry 타입이 적절한지
- **정렬 안정성**: 동점자 처리가 올바른지
- **메모리 관리**: 리더보드 크기 제한이 적절한지
- **접근성**: 리더보드 UI의 ARIA 속성, 키보드 탐색
- **반응형**: 모바일에서 테이블 레이아웃이 깨지지 않는지
- **엣지 케이스**: 빈 리더보드, 동일 닉네임, 특수문자 닉네임

## 3. 영구 저장 기능 제안 (`persist`)

localStorage를 사용한 리더보드 영구 저장 기능의 구현 방안을 제시합니다.

### 분석 항목
- 현재 인메모리 상태의 한계점
- localStorage 키 네이밍 전략
- 데이터 직렬화/역직렬화 방안 (Grade 객체 포함)
- 용량 제한 및 에러 처리 (QuotaExceededError)
- 데이터 마이그레이션 (스키마 버전 관리)

### 출력 형식

수정이 필요한 파일별로 **변경 전/후 코드**를 제시합니다.
사용자 승인 없이 파일을 수정하지 않습니다.

---

## 4. 데이터 내보내기 제안 (`export`)

리더보드 데이터를 외부로 내보내는 기능의 구현 방안을 제시합니다.

### 분석 항목
- CSV 다운로드 기능
- 클립보드 복사 기능 (텍스트 표 형식)
- 공유 기능 (카카오톡/트위터 등 SNS 공유 텍스트)

### 출력 형식

각 내보내기 방식별로 구현 코드와 UI 배치를 제안합니다.
사용자 승인 없이 파일을 수정하지 않습니다.
