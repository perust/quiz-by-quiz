학생 간 성적을 나란히 비교합니다.

## 매개변수

- `$ARGUMENTS`: 비교할 학생 이름 2~6명 (공백 또는 쉼표로 구분)
  - 예: `김민준 이서연` 또는 `김민준, 이서연, 박지호`
- `$ARGUMENTS`가 비어 있거나 이름이 1개이면 사용법을 안내합니다.

## 작업 순서

### Step 1: 파일 읽기

`quiz-challenge/src/data/students.ts` 파일을 읽습니다.

**이 단계에서 오류가 발생하면**: "학생 데이터가 없습니다. `/quiz-teacher-register 이름 점수`로 먼저 학생을 등록하세요." 메시지를 출력하고 중단합니다.

### Step 2: 학생 매칭

`$ARGUMENTS`에서 이름을 추출하고 각각을 학생 데이터에서 찾습니다.

- 공백 또는 쉼표로 이름을 분리합니다.
- 찾지 못한 이름이 있으면 경고를 표시하되, 2명 이상 찾으면 비교를 계속합니다.
- 2명 미만이면 전체 학생 목록을 보여주고 중단합니다.

### Step 3: 기본 비교표

```
## 🔍 학생 비교: [이름1] vs [이름2] (vs ...)

### 📋 기본 정보 비교

| 항목 | [이름1] | [이름2] | ... |
|------|---------|---------|-----|
| 최신 총점 | N/40 | N/40 | |
| 등급 | 🌟 A | 📚 B | |
| 응시 횟수 | N회 | N회 | |
| 최근 응시일 | | | |
```

### Step 4: 카테고리별 비교

```
### 📊 카테고리별 비교

#### 🏛️ 한국사
| 학생 | 점수 | 바 차트 |
|------|------|---------|
| [이름1] | N/10 | █████████░ |
| [이름2] | N/10 | ██████░░░░ |

#### 🔬 과학
| 학생 | 점수 | 바 차트 |
|------|------|---------|
| [이름1] | N/10 | ████████░░ |
| [이름2] | N/10 | █████████░ |

#### 🌍 지리
| 학생 | 점수 | 바 차트 |
|------|------|---------|
| [이름1] | N/10 | █████████░ |
| [이름2] | N/10 | ███████░░░ |

#### 🎨 예술과문화
| 학생 | 점수 | 바 차트 |
|------|------|---------|
| [이름1] | N/10 | ████████░░ |
| [이름2] | N/10 | ██████████ |
```

바 차트: █ 최대 10칸, 빈 부분은 ░

### Step 5: 종합 비교 차트

```
### 📈 종합 비교 차트

| 카테고리 | [이름1] | [이름2] | 차이 | 우위 |
|----------|---------|---------|------|------|
| 🏛️ 한국사 | N/10 | N/10 | ±N | [이름] |
| 🔬 과학 | N/10 | N/10 | ±N | [이름] |
| 🌍 지리 | N/10 | N/10 | ±N | [이름] |
| 🎨 예술과문화 | N/10 | N/10 | ±N | [이름] |
| **총점** | **N/40** | **N/40** | **±N** | **[이름]** |
```

### Step 6: 강점/약점 비교

```
### 💪 강점 & 약점

| 분석 | [이름1] | [이름2] |
|------|---------|---------|
| 강점 | 🏛️ 한국사 (N/10) | 🎨 예술과문화 (N/10) |
| 약점 | 🎨 예술과문화 (N/10) | 🌍 지리 (N/10) |
| 가장 큰 차이 | [카테고리] ±N점 차이 | |
```

### Step 7: 성적 추이 비교 (2회 이상 응시한 학생이 있는 경우)

```
### 📉 성적 추이 비교

| 학생 | 1회차 | 최신 | 변화 | 추세 |
|------|-------|------|------|------|
| [이름1] | N/40 | N/40 | ▲+N | 📈 상승 |
| [이름2] | N/40 | — | — | 1회 응시 |
```

### Step 8: 비교 요약

```
### 📝 비교 요약

**총평**:
- [이름1]은(는) [강점 설명], [이름2]은(는) [강점 설명]
- 가장 큰 차이는 [카테고리]에서 나타남 (N점 차이)
- [구체적인 상호 학습 제안 또는 각자 개선 방향]
```

마지막에 다음 안내를 추가합니다:
```
💡 학생 상세 조회: `/quiz-teacher-student 이름`
💡 전체 순위표: `/quiz-teacher-rank`
💡 통합 대시보드: `/quiz-teacher-dashboard`
```
