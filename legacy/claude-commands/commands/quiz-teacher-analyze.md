반 전체의 성과를 분석합니다.

## 매개변수

- `$ARGUMENTS`: 분석 범위 (선택사항)
  - 빈값 또는 `전체`: 종합 분석 (기본값)
  - `카테고리`: 카테고리별 심층 분석
  - `추이`: 시간에 따른 성적 변화 분석

## 작업 순서

### Step 1: 파일 읽기

`quiz-challenge/src/data/students.ts` 파일을 읽습니다.

**이 단계에서 오류가 발생하면**: "학생 데이터가 없습니다. `/quiz-teacher-register 이름 점수`로 먼저 학생을 등록하세요." 메시지를 출력하고 중단합니다.

### Step 2: 반 개요

```
## 📊 반 전체 성과 분석

### 🏫 반 개요

| 항목 | 값 |
|------|-----|
| 총 학생 수 | N명 |
| 총 응시 횟수 | N회 |
| 평균 응시 횟수 | N.N회/인 |
| 반 평균 점수 | N.N / 40 |
| 반 평균 등급 | |
| 점수 범위 | N ~ N / 40 |
```

### Step 3: 등급 분포 분석

```
### 📈 등급 분포

| 등급 | 인원 | 비율 | 분포 |
|------|------|------|------|
| 👑 S (38-40) | N명 | N% | ████░░░░░░░░░░░░░░░░ |
| 🌟 A (32-37) | N명 | N% | ████████░░░░░░░░░░░░ |
| 📚 B (24-31) | N명 | N% | ████████████░░░░░░░░ |

**분포 판정**: 🟢 정상 / 🟡 편중 / 🔴 심각 편중
```

- 분포 바 차트: █ 최대 20칸, 비율에 비례
- 판정 기준: 특정 등급에 60% 이상 집중 → 🔴, 50% 이상 → 🟡, 그 외 → 🟢
