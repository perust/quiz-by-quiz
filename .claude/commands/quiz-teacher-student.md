개별 학생의 상세 성적을 조회합니다.

## 매개변수

- `$ARGUMENTS`: 학생 이름 (예: `김민준`)
- `$ARGUMENTS`가 비어 있으면 전체 학생 목록을 보여주고 선택을 안내합니다.

## 작업 순서

### Step 1: 파일 읽기

`quiz-challenge/src/data/students.ts` 파일을 읽습니다.

**이 단계에서 오류가 발생하면**: "학생 데이터가 없습니다. `/quiz-teacher-register 이름 점수`로 먼저 학생을 등록하세요." 메시지를 출력하고 중단합니다.

### Step 2: 학생 검색

`$ARGUMENTS`와 일치하는 학생을 찾습니다.

- 정확히 일치하는 이름이 없으면 부분 일치 검색을 시도합니다.
- 여전히 없으면 등록된 전체 학생 목록을 보여주고 중단합니다.

### Step 3: 최신 성적 카드 출력

```
## 🎓 [이름] 학생 성적 상세

### 📊 기본 정보

| 항목 | 값 |
|------|-----|
| 이름 | |
| 등록일 | |
| 응시 횟수 | N회 |
| 최근 응시일 | |
| 최신 총점 | /40 |
| 최신 등급 | |
```

### Step 4: 카테고리별 분석

최신 결과 기준으로 카테고리별 상세 분석을 출력합니다:

```
### 📈 카테고리별 성적

| 카테고리 | 점수 | 바 차트 | 평가 |
|----------|------|---------|------|
| 🏛️ 한국사 | /10 | ██████████ | ✅ 우수 |
| 🔬 과학 | /10 | ████████░░ | 🟢 양호 |
| 🌍 지리 | /10 | ██████░░░░ | 🟡 보통 |
| 🎨 예술과문화 | /10 | ████░░░░░░ | 🟠 미흡 |
```

바 차트: █ 최대 10칸, 빈 부분은 ░

평가 기준:
| 점수 | 평가 |
|------|------|
| 9-10 | ✅ 우수 |
| 7-8 | 🟢 양호 |
| 5-6 | 🟡 보통 |
| 3-4 | 🟠 미흡 |
| 0-2 | 🔴 부진 |

### Step 5: 강점/약점 분석

```
### 💪 강점 & 약점

**강점 카테고리**: 🏛️ 한국사 (10/10)
- [구체적인 칭찬 코멘트]

**약점 카테고리**: 🎨 예술과문화 (4/10)
- [구체적인 학습 권장 사항]
```

- 가장 높은 점수 카테고리 = 강점
- 가장 낮은 점수 카테고리 = 약점

### Step 6: 성적 추이 (2회 이상 응시한 경우)

```
### 📉 성적 추이

| # | 날짜 | 총점 | 등급 | 변화 | 한국사 | 과학 | 지리 | 예술 |
|---|------|------|------|------|--------|------|------|------|
| 1 | | /40 | | — | | | | |
| 2 | | /40 | | ▲+3 | | | | |

**추이 분석**: [총점 변화 패턴 설명, 개선된 카테고리, 하락한 카테고리 분석]
```

- 점수 상승: ▲+N (초록)
- 점수 하락: ▼-N (빨강)
- 변화 없음: → (회색)

### Step 7: 학습 권장사항

```
### 📚 맞춤 학습 권장

1. **[약점 카테고리]** 집중 학습 권장
   - 현재 점수: N/10 → 목표: N+2/10
   - [구체적인 학습 조언]

2. **[보통 카테고리]** 보강 권장
   - 현재 점수: N/10 → 목표: N+1/10
   - [구체적인 학습 조언]

3. **[강점 카테고리]** 유지
   - 현재 점수: N/10 — 잘 하고 있습니다!
```

```
💡 다른 학생과 비교: `/quiz-teacher-compare 이름1 이름2`
💡 반 전체 분석: `/quiz-teacher-analyze`
```
