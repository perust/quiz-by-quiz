`quiz-challenge/src/data/questions.ts`의 퀴즈 데이터를 분석하여 종합 통계를 출력합니다.

## 카테고리 필터

- `$ARGUMENTS` 값이 있으면 해당 카테고리(한국사, 과학, 지리, 예술과문화)의 문제만 분석합니다.
- `$ARGUMENTS` 값이 비어 있으면 전체 문제를 분석합니다.

## 작업 순서

### 1. 파일 읽기

`quiz-challenge/src/data/questions.ts` 파일을 읽고 전체 문제 데이터를 파싱합니다.

### 2. 전체 개요

| 항목 | 값 |
|------|-----|
| 총 문제 수 | |
| 카테고리 수 | |
| 카테고리별 문제 수 | 한국사: / 과학: / 지리: / 예술과문화: |
| ID 범위 | ~ |
| ID 연속성 | 연속 / 불연속 (빈 ID 목록) |

### 3. 카테고리별 분석

각 카테고리에 대해 아래 표를 출력합니다:

#### 📊 [카테고리명] (N문제)

**난이도 분포:**

| 난이도 | 문제 수 | 비율 | 권장 비율 | 편차 | ID 목록 |
|--------|---------|------|-----------|------|---------|
| 쉬움   |         |      | 30%       |      |         |
| 보통   |         |      | 40%       |      |         |
| 어려움 |         |      | 30%       |      |         |

**정답 분포:**

| 정답 번호 | 보기 위치 | 문제 수 | 비율 | 권장 비율 | 편차 | ID 목록 |
|-----------|-----------|---------|------|-----------|------|---------|
| 0         | A (첫째)  |         |      | 25%       |      |         |
| 1         | B (둘째)  |         |      | 25%       |      |         |
| 2         | C (셋째)  |         |      | 25%       |      |         |
| 3         | D (넷째)  |         |      | 25%       |      |         |

### 4. 전체 통합 분포

#### 전체 난이도 분포

| 난이도 | 문제 수 | 비율 | 바 차트 |
|--------|---------|------|---------|
| 쉬움   |         |      | █████   |
| 보통   |         |      | █████   |
| 어려움 |         |      | █████   |

#### 전체 정답 분포

| 정답 번호 | 문제 수 | 비율 | 바 차트 |
|-----------|---------|------|---------|
| 0 (A)     |         |      | █████   |
| 1 (B)     |         |      | █████   |
| 2 (C)     |         |      | █████   |
| 3 (D)     |         |      | █████   |

바 차트는 비율에 비례하여 █ 문자로 시각화합니다 (최대 20칸).

### 5. 균형도 평가

#### 난이도 균형

| 카테고리 | 쉬움 | 보통 | 어려움 | 균형 점수 | 판정 |
|----------|------|------|--------|-----------|------|

- **균형 점수**: 권장 비율(3:4:3)과의 편차 합 (0에 가까울수록 좋음)
- **판정**: ✅ 양호 (편차 합 ≤ 15%) / ⚠️ 보통 (≤ 30%) / ❌ 불균형 (> 30%)

#### 정답 균형

| 카테고리 | 0번 | 1번 | 2번 | 3번 | 균형 점수 | 판정 |
|----------|-----|-----|-----|-----|-----------|------|

- **균형 점수**: 이상 비율(각 25%)과의 편차 합 (0에 가까울수록 좋음)
- **판정**: ✅ 양호 (편차 합 ≤ 20%) / ⚠️ 보통 (≤ 40%) / ❌ 불균형 (> 40%)

### 6. 문제점 및 개선 제안

발견된 불균형이나 문제점을 정리합니다:

```
🔴 심각 — [설명]
🟡 주의 — [설명]
🟢 양호 — [설명]
```

각 문제점에 대해 구체적인 개선 방법을 제안합니다.
(예: "한국사 카테고리의 정답 3번 비율이 40%로 높습니다. ID 1번 문제의 보기 순서를 재배치하면 균형을 맞출 수 있습니다.")
