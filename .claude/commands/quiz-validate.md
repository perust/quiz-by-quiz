`data/`의 **문제와 해설**에서 최상급·순위 표현을 찾아, 표현마다 **어떤 기준을 명시해야 하는지** 알려줘.

최상급은 기준이 빠지면 정답이 갈린다. "가장 높은 산"은 해발 고도 기준이면 에베레스트,
산기슭부터 재면 마우나케아, 지구 중심에서 재면 침보라소다. 그래서 표현을 찾는 것 자체가
목적이 아니라, 찾은 표현마다 **무엇을 재는지가 문장에 박혀 있는지** 보는 것이 목적이다.
판정 근거는 `CLAUDE.md`의 문제 작성 규칙 2번(측정 기준), 3번(시간·범위), 4번(교차 검증)이다.

문제와 해설은 걸리는 이유가 다르다. 문제의 최상급은 **정답을 흔들고**, 해설의 최상급·순위는
정답에는 영향이 없어도 **틀린 사실을 가르친다.** 그래서 판정 기준을 나눠서 본다.

## 1. 스캔

아래를 그대로 실행한다. 카테고리 지정은 스크립트가 처리하므로 결과를 손으로 추리지 않는다.

- 인자가 카테고리면 그 카테고리만 검사한다. 한글 이름(`한국사`)과 영문 코드(`history`) 둘 다 받는다
- 인자가 없으면 전체를 검사한다
- 인자가 카테고리가 아니면 안내를 찍고 전체를 검사한다

```bash
QUIZ_CATEGORY="$ARGUMENTS" python3 - <<'PY'
import json, glob, os, re

CATEGORIES = ('history', 'science', 'geography', 'general', 'art')
# 한글 이름도 그대로 받는다. js/constants.js의 CATEGORIES 이름과 맞춘다
ALIASES = {'한국사': 'history', '과학': 'science', '지리': 'geography',
           '일반상식': 'general', '예술과문화': 'art'}
NAMES = {code: ko for ko, code in ALIASES.items()}
TERMS = [
    # 최상급
    '가장', '제일', '최초', '최대', '최소', '최고', '최장', '최단', '최상', '유일', '으뜸',
    # 순위·서수 — 해설에서 "두 번째인 거제도"처럼 검증이 필요한 주장이 나온다
    r'\d+\s*번째', r'[첫둘두셋세넷네]\s*번째', '첫째', '둘째', '셋째', r'\d+\s*위',
]
PATTERN = re.compile('|'.join(TERMS))
FIELDS = ('question', 'explanation')
LABEL = {'question': '문제', 'explanation': '해설'}

requested = (os.environ.get('QUIZ_CATEGORY') or '').strip()
lowered = requested.lower()
target = lowered if lowered in CATEGORIES else ALIASES.get(requested)
if requested and target is None:
    print(f"'{requested}'은(는) 카테고리가 아닙니다. 전체를 검사합니다.")
    print('쓸 수 있는 값: ' + ', '.join(f'{ko}({code})' for ko, code in ALIASES.items()) + '\n')

paths = [f'data/{target}.json'] if target else sorted(glob.glob('data/*.json'))
label = f'{NAMES[target]} ({target})' if target else '전체 카테고리'
print(f'검사 대상: {label}\n')

total, rows, broken = 0, [], []
for path in paths:
    try:
        data = json.load(open(path, encoding='utf-8'))
    except Exception as error:
        broken.append(f'{path}: {error}')
        continue
    for q in data:
        total += 1
        for field in FIELDS:
            hits = sorted(set(PATTERN.findall(q.get(field) or '')))
            if hits:
                rows.append((q.get('id', '?'), field, ', '.join(hits), q.get(field) or ''))

q_count = sum(1 for r in rows if r[1] == 'question')
print(f'문제 {total}개 중 {len(rows)}건 (문제 {q_count} · 해설 {len(rows) - q_count})\n')
for qid, field, hits, text in rows:
    print(f'[{qid}] {LABEL[field]} — 표현: {hits}')
    print(f'  {text}\n')
for b in broken:
    print(f'!! 읽기 실패 {b}')
PY
```

## 2. 판정

걸린 표현마다 **이 최상급이 어떤 기준을 요구하는지 먼저 말하고**, 그 기준이 문장에 있는지 본다.
기준을 지목할 때는 "무엇으로 재느냐에 따라 답이 어떻게 갈리는지"를 함께 적는다.
"기준이 없습니다"로 끝내면 쓸모가 없고, "면적 기준인지 인구 기준인지 밝혀야 합니다"까지 가야 한다.

### 표현별로 필요한 기준

자주 나오는 것들이다. 목록에 없으면 같은 방식으로 갈릴 수 있는 축을 직접 따진다.

| 표현 | 갈릴 수 있는 기준 | 명시한 예 |
| --- | --- | --- |
| 가장 큰 / 넓은 | 면적 · 인구 · 경제 규모 · 부피 | `면적이 가장 넓은` |
| 가장 높은 | 해발 고도 · 기슭부터의 높이 · 층수 · 첨탑 포함 여부 | `해발 고도가 가장 높은` |
| 가장 긴 | 총 길이 · 본류 길이 · 국내 구간 | `총 길이가 가장 긴` |
| 가장 오래된 | 창건 · 현존 · 기록상 최초 | `현존하는 가장 오래된` |
| 최초의 | 발명 · 특허 · 상용화 · 일반 공개 | `상용화된 최초의` |
| 최대 / 최다 | 규모 · 생산량 · 매출 · 수용 인원 | `연간 생산량이 가장 많은` |
| 가장 빠른 | 최고 속도 · 평균 속도 · 가속 | `최고 속도가 가장 빠른` |
| N번째 / N위 | 무엇을 기준으로 매긴 순위인가 | `면적 기준 두 번째로 큰` |

### 문제에서 걸린 것 — 정답이 갈리는가

**기준** — 위 표대로 무엇을 재는지가 문장에 있는가
- 있음: `면적이 가장 넓은`, `해발 고도가 가장 높은`, `지름이 가장 큰`, `날수가 가장 적은`
- 없음: `가장 큰 나라는?`, `가장 높은 산은?`

**범위** — 어디까지를 놓고 비교하는지가 한정돼 있는가
- 있음: `대한민국에서`, `태양계에서`, `1년 열두 달 중`, `태양계에서 ... 행성`(지리적 + 분류적)
- 없음: 범위어가 아예 없는 경우. 보기가 우연히 좁혀줘도 문장만으로 성립해야 한다
- 시점에 따라 답이 변하는 내용이면 기준 연도도 있어야 한다

### 해설에서 걸린 것 — 그 주장이 방어되는가

해설은 정답을 정하지 않으므로 문장에 기준·범위를 다시 붙일 필요는 없다. 대신 이걸 본다.

- **사실로 방어되는가** — 출처마다 값이 갈리는 순위·수치를 단정하고 있지 않은가.
  1·2위 격차가 근소한 순위, 재측정으로 바뀌는 수치가 특히 위험하다 (규칙 4)
- **문제의 기준과 어긋나지 않는가** — 문제는 면적 기준인데 해설이 인구 순위를 말하면 읽는 사람이 헷갈린다
- **덧붙인 최상급이 필요한가** — 정답 설명에 보탬이 안 되는 단정은 위험만 늘린다

애매하면 원문을 `data/`에서 직접 읽고, 순위·연도·수치가 걸리면 교차 검증한다.

## 3. 출력

걸린 것을 **하나도 빠뜨리지 말고** 낸다. 통과한 것도 남겨야 다음에 다시 훑지 않는다.
맨 위에 검사 대상 카테고리를 한 줄로 밝힌다. 문제와 해설은 판정 기준이 달라 표를 나누고,
해당 없는 표는 생략한다.

**문제 문장**

| ID | 문제 | 표현 | 필요한 기준 | 명시된 기준 | 범위 | 판정 |
| --- | --- | --- | --- | --- | --- | --- |
| geography-003 | 지구에서 해발 고도가 가장 높은 산은? | 가장 | 해발 고도인지 기슭부터의 높이인지 | 해발 고도 | 지구 | OK |

**해설**

| ID | 해설 | 표현 | 주장 | 판정 |
| --- | --- | --- | --- | --- |
| science-003 | 목성의 지름은 지구의 약 11배로… | 가장 | 태양계 행성 중 지름 최대 | OK |

`판정`은 `OK` 또는 `보완 필요`. 보완이 필요하면 표 아래에 항목별로 **어떤 기준이 빠졌는지,
그 기준에 따라 답이 어떻게 갈리는지, 고친 문장안**을 적는다.
고치라는 지시가 없으면 파일은 건드리지 말고 제안까지만 한다.

마지막에 한 줄로 정리한다: 검사 대상, 검사한 문제 수, 문제·해설별 적발 수, 보완이 필요한 수.

## 알아둘 것

- 검사 대상은 `question`과 `explanation`이다. **보기(`choices`)의 최상급은 잡지 않는다**
- 정규식은 표현의 **존재**만 찾는다. 기준·범위가 붙었는지, 주장이 사실인지는 읽고 판정해야 한다
- 반대로 최상급 없이도 정답이 갈리는 문제는 이 명령어가 못 잡는다. 그건 규칙 1·5의 몫이다
- 순위 표현은 오탐이 난다(`4위 타자`처럼 최상급이 아닌 쓰임). 걸러내되 왜 뺐는지 한 줄 남긴다
