선생님 모드 통합 대시보드입니다. 반 전체 또는 특정 학생 중심의 종합 보고서를 출력합니다.

## 매개변수

- `$ARGUMENTS`: 선택사항
  - 빈값: **반 전체 모드** — 반 전체 종합 보고서
  - 학생 이름: **학생 중심 모드** — 해당 학생을 중심으로 한 보고서

## 작업 순서

### Step 1: 파일 읽기

`quiz-challenge/src/data/students.ts` 파일을 읽습니다.

**이 단계에서 오류가 발생하면**: 아래 안내를 출력하고 중단합니다:

```
## ❌ 학생 데이터가 없습니다

학생을 먼저 등록해 주세요:

1. `/quiz-teacher-register 이름 점수` — 학생 등록 및 점수 입력
   - 예: `/quiz-teacher-register 홍길동 34`
   - 예: `/quiz-teacher-register 홍길동 9,8,9,8`

2. 여러 명 등록 후 다시 `/quiz-teacher-dashboard` 실행
```

### Step 2: 모드 결정

- `$ARGUMENTS`가 비어 있으면 → **반 전체 모드** (Step 3A로 진행)
- `$ARGUMENTS`에 이름이 있으면 → 학생 검색 후 **학생 중심 모드** (Step 3B로 진행)
  - 이름을 찾지 못하면 전체 학생 목록 표시 후 반 전체 모드로 대체 실행

---

## 반 전체 모드 (Step 3A)

### Step 3A-1: 대시보드 헤더

```
# 📋 선생님 대시보드 — 반 전체 보고서

> 📅 [현재 날짜] | 👨‍🏫 총 N명 | 📝 총 N회 응시
```

### Step 3A-2: 순위표 (quiz-teacher-rank 핵심 요약)

```
## 🏆 학생 순위표

| 순위 | 이름 | 총점 | 등급 | 🏛️ | 🔬 | 🌍 | 🎨 |
|------|------|------|------|-----|-----|-----|-----|
| 🥇 1 | | /40 | | /10 | /10 | /10 | /10 |
| 🥈 2 | | /40 | | /10 | /10 | /10 | /10 |
| 🥉 3 | | /40 | | /10 | /10 | /10 | /10 |
```

최신 결과 기준 총점 내림차순 정렬.

### Step 3A-3: 등급 분포 (quiz-teacher-analyze 핵심)

```
## 📊 등급 분포

| 등급 | 인원 | 분포 |
|------|------|------|
| 👑 S | N명 | ████░░░░░░░░░░░░░░░░ |
| 🌟 A | N명 | ████████░░░░░░░░░░░░ |
| 📚 B | N명 | ████████████░░░░░░░░ |
| 📖 C | N명 | ████░░░░░░░░░░░░░░░░ |
| 📝 D | N명 | ░░░░░░░░░░░░░░░░░░░░ |
```

### Step 3A-4: 카테고리별 반 성적

```
## 🏛️🔬🌍🎨 카테고리별 반 성적

| 카테고리 | 반 평균 | 바 차트 | 진단 |
|----------|---------|---------|------|
| 🏛️ 한국사 | N.N/10 | ███████░░░ | 🟢 |
| 🔬 과학 | N.N/10 | ██████░░░░ | 🟡 |
| 🌍 지리 | N.N/10 | ████████░░ | 🟢 |
| 🎨 예술과문화 | N.N/10 | █████░░░░░ | 🟡 |
```

진단 기준: 8.0↑ 🟢, 6.0↑ 🟡, 4.0↑ 🟠, 4.0↓ 🔴

### Step 3A-5: 관심 필요 학생

```
## ⚠️ 관심 필요 학생

| 학생 | 총점 | 주요 약점 | 권장 조치 |
|------|------|-----------|-----------|
| | N/40 | [카테고리] N/10 | [구체적 제안] |
```

- 총점 하위 25% 또는 특정 카테고리 3점 이하인 학생만 표시
- 해당 학생이 없으면 "✅ 특별히 주의가 필요한 학생이 없습니다." 표시

### Step 3A-6: 핵심 인사이트

```
## 🔍 핵심 인사이트

1. **전체 수준**: [한 줄 평가] [🟢/🟡/🔴]
2. **강점 카테고리**: [카테고리] — 반 평균 N.N/10
3. **약점 카테고리**: [카테고리] — 반 평균 N.N/10, 보강 필요
4. **성적 격차**: 최고 N점 ~ 최저 N점 (N점 차이) [🟢/🟡/🔴]
5. **추천 조치**: [가장 우선적으로 필요한 한 가지 조치]
```

### Step 3A-7: 커맨드 안내

```
---

### 🔧 세부 분석 커맨드

| 커맨드 | 설명 |
|--------|------|
| `/quiz-teacher-student 이름` | 학생 상세 성적 조회 |
| `/quiz-teacher-rank 기준` | 순위표 (총점/평균/카테고리/성장률) |
| `/quiz-teacher-analyze` | 반 전체 심층 분석 |
| `/quiz-teacher-compare 이름1 이름2` | 학생 간 비교 |
| `/quiz-teacher-register 이름 점수` | 학생 추가/점수 입력 |
```

## 학생 중심 모드 (Step 3B)

### Step 3B-1: 대시보드 헤더

```
# 📋 선생님 대시보드 — [이름] 학생 보고서

> 📅 [현재 날짜] | 🎓 [이름] | 등록일: [날짜] | 응시 N회
```

### Step 3B-2: 학생 카드 (quiz-teacher-student 핵심)

```
## 🎓 학생 카드

| 항목 | 값 |
|------|-----|
| 이름 | |
| 최신 총점 | N/40 |
| 등급 | |
| 응시 횟수 | N회 |

### 카테고리별 성적

| 카테고리 | 점수 | 바 차트 | 평가 |
|----------|------|---------|------|
| 🏛️ 한국사 | N/10 | ██████████ | ✅ 우수 |
| 🔬 과학 | N/10 | ████████░░ | 🟢 양호 |
| 🌍 지리 | N/10 | ██████░░░░ | 🟡 보통 |
| 🎨 예술과문화 | N/10 | ████░░░░░░ | 🟠 미흡 |
```

평가 기준: 9-10 ✅우수, 7-8 🟢양호, 5-6 🟡보통, 3-4 🟠미흡, 0-2 🔴부진

### Step 3B-3: 반 내 위치

```
## 📍 반 내 위치

| 항목 | 값 |
|------|-----|
| 순위 | N등 / N명 |
| 반 평균 대비 | +N점 (상위) 또는 -N점 (하위) |
| 백분위 | 상위 N% |

### 카테고리별 반 평균 대비

| 카테고리 | 본인 | 반 평균 | 차이 | 비교 |
|----------|------|---------|------|------|
| 🏛️ 한국사 | N/10 | N.N/10 | +N.N | 📈 반 평균 이상 |
| 🔬 과학 | N/10 | N.N/10 | -N.N | 📉 반 평균 이하 |
```

### Step 3B-4: 성적 추이 (2회 이상 응시 시)

```
## 📉 성적 추이

| # | 날짜 | 총점 | 등급 | 변화 |
|---|------|------|------|------|
| 1 | | N/40 | | — |
| 2 | | N/40 | | ▲+N |

**추이 분석**: [변화 패턴 설명]
```

1회만 응시한 경우: "아직 추이 데이터가 없습니다. 추가 응시 후 확인하세요."

### Step 3B-5: 유사 학생 비교 (quiz-teacher-compare 핵심)

총점이 가장 가까운 학생 1~2명을 자동으로 선택하여 간략 비교합니다.

```
## 🔍 유사 수준 학생 비교

| 항목 | [이름] | [유사학생1] | [유사학생2] |
|------|--------|-------------|-------------|
| 총점 | N/40 | N/40 | N/40 |
| 등급 | | | |
| 강점 | [카테고리] | [카테고리] | [카테고리] |
| 약점 | [카테고리] | [카테고리] | [카테고리] |
```

학생이 2명 이하이면 이 섹션을 건너뜁니다.

### Step 3B-6: 맞춤 학습 권장

```
## 📚 맞춤 학습 권장

1. **[최우선 약점 카테고리]** — 집중 학습 권장 🔴
   - 현재: N/10 → 목표: N/10
   - [구체적 학습 조언]

2. **[보강 카테고리]** — 추가 학습 권장 🟡
   - 현재: N/10 → 목표: N/10
   - [구체적 학습 조언]

3. **[강점 카테고리]** — 유지 🟢
   - 현재: N/10 — 잘 하고 있습니다!
```

| `/quiz-teacher-rank` | 전체 순위표 |
| `/quiz-teacher-dashboard` | 반 전체 대시보드 |
