학생을 등록하고 퀴즈 점수를 입력합니다.

## 매개변수

- `$ARGUMENTS` 형식: `이름 점수`
  - 이름: 학생 이름 (예: `홍길동`)
  - 점수: 총점 하나 (예: `34`) 또는 카테고리별 점수 쉼표 구분 (예: `9,8,9,8` → 한국사,과학,지리,예술과문화 순)
- 예시: `/quiz-teacher-register 홍길동 34` 또는 `/quiz-teacher-register 홍길동 9,8,9,8`
- `$ARGUMENTS`가 비어 있으면 사용법을 안내합니다.

## 작업 순서

### Step 1: 매개변수 파싱

`$ARGUMENTS`에서 이름과 점수를 분리합니다.

- 공백으로 분리하여 첫 번째 토큰 = 이름, 두 번째 토큰 = 점수
- 점수가 쉼표를 포함하면 카테고리별 점수로 파싱: `한국사,과학,지리,예술과문화`
- 점수가 숫자 하나면 총점으로 처리 (카테고리별 점수는 균등 배분으로 추정)
- 각 카테고리 점수는 0~10 범위, 총점은 0~40 범위

**이 단계에서 오류가 발생하면**: 올바른 사용법 예시를 보여주고 중단합니다.

### Step 2: 파일 읽기

`quiz-challenge/src/data/students.ts` 파일을 읽습니다.

- 파일이 없으면 새로 생성합니다 (빈 배열로 초기화).

### Step 3: 학생 등록/업데이트

**기존 학생인 경우** (id가 이름과 일치하는 학생이 있으면):
- `results` 배열에 새 결과를 추가합니다.

**신규 학생인 경우**:
- 새 `StudentProfile` 객체를 생성하여 배열에 추가합니다.

등급은 아래 기준으로 자동 부여:
| 등급 | 점수 범위 | 타이틀 |
|-----|----------|--------|
| S (👑) | 38-40 | 상식왕 |
| A (🌟) | 32-37 | 박학다식 |
| B (📚) | 24-31 | 준수함 |
| C (📖) | 16-23 | 노력필요 |
| D (📝) | 0-15  | 기초부터 |

현재 날짜/시간을 `date`와 `registeredAt`에 기록합니다 (형식: `2026.02.08 14:30`).

### Step 4: 파일 저장

`quiz-challenge/src/data/students.ts` 파일을 업데이트합니다.
기존 파일 형식(import문, export문)을 유지합니다.

### Step 5: 결과 출력

```
## 📋 학생 등록 완료

| 항목 | 값 |
|------|-----|
| 이름 | |
| 등록일 | |
| 총점 | /40 |
| 등급 | |

### 카테고리별 점수

| 카테고리 | 점수 | 바 차트 |
|----------|------|---------|
| 🏛️ 한국사 | /10 | ██████░░░░ |
| 🔬 과학 | /10 | ██████░░░░ |
| 🌍 지리 | /10 | ██████░░░░ |
| 🎨 예술과문화 | /10 | ██████░░░░ |
```

바 차트는 █ 최대 10칸, 빈 부분은 ░로 표시합니다.

**기존 학생인 경우** 추가로 누적 기록을 보여줍니다:

```
### 📈 누적 기록 (N회 응시)

| # | 날짜 | 총점 | 등급 | 변화 |
|---|------|------|------|------|
| 1 | | /40 | | — |
| 2 | | /40 | | +N점 또는 -N점 |
```

마지막에 다음 안내를 추가합니다:
```
💡 상세 성적 조회: `/quiz-teacher-student 이름`
💡 전체 순위표: `/quiz-teacher-rank`
```
