전체 학생의 순위표를 출력합니다.

## 매개변수

- `$ARGUMENTS`: 정렬 기준 (선택사항)
  - 빈값 또는 `총점`: 최신 총점 기준 (기본값)
  - `평균`: 전체 응시 평균 점수 기준
  - `한국사`, `과학`, `지리`, `예술과문화`: 해당 카테고리 최신 점수 기준
  - `성장률`: 최근 2회 응시 점수 변화량 기준

## 작업 순서

### Step 1: 파일 읽기

`quiz-challenge/src/data/students.ts` 파일을 읽습니다.

**이 단계에서 오류가 발생하면**: "학생 데이터가 없습니다. `/quiz-teacher-register 이름 점수`로 먼저 학생을 등록하세요." 메시지를 출력하고 중단합니다.

### Step 2: 정렬 기준 파싱

`$ARGUMENTS`를 파싱하여 정렬 기준을 결정합니다.
인식할 수 없는 값이면 기본값(총점)으로 처리하되 안내 메시지를 출력합니다.

### Step 3: 순위표 출력

```
## 🏆 학생 순위표

> 정렬 기준: [기준명] | 총 N명

| 순위 | 이름 | 총점 | 등급 | 🏛️한국사 | 🔬과학 | 🌍지리 | 🎨예술 | 응시 |
|------|------|------|------|----------|--------|--------|--------|------|
| 🥇 1 | | /40 | | /10 | /10 | /10 | /10 | N회 |
| 🥈 2 | | /40 | | /10 | /10 | /10 | /10 | N회 |
| 🥉 3 | | /40 | | /10 | /10 | /10 | /10 | N회 |
| 4 | | /40 | | /10 | /10 | /10 | /10 | N회 |
```

- 1~3위는 🥇🥈🥉 메달 이모지를 표시합니다.
- 동점이면 같은 순위를 부여합니다.
- 카테고리별 점수는 최신 결과 기준입니다.
- `성장률` 정렬 시 추가 열: `성장` (▲+N / ▼-N / 1회만 응시)

### Step 4: 등급 분포

```
### 📊 등급 분포

| 등급 | 인원 | 비율 | 분포 |
|------|------|------|------|
| 👑 S (38-40) | N명 | N% | ████░░░░░░░░░░░░░░░░ |
| 🌟 A (32-37) | N명 | N% | ████████░░░░░░░░░░░░ |
| 📚 B (24-31) | N명 | N% | ████████████░░░░░░░░ |
| 📖 C (16-23) | N명 | N% | ████░░░░░░░░░░░░░░░░ |
| 📝 D (0-15)  | N명 | N% | ░░░░░░░░░░░░░░░░░░░░ |
```

분포 바 차트: █ 최대 20칸, 비율에 비례

### Step 5: 통계 요약

```
### 📈 통계 요약

| 항목 | 값 |
|------|-----|
| 총 학생 수 | N명 |
| 평균 점수 | N.N / 40 |
| 중앙값 | N / 40 |
| 최고 점수 | N / 40 (이름) |
| 최저 점수 | N / 40 (이름) |
| 표준편차 | N.N |
| 평균 등급 | |
```

### Step 6: 카테고리별 반 평균

```
### 🏫 카테고리별 반 평균

| 카테고리 | 반 평균 | 바 차트 | 평가 |
|----------|---------|---------|------|
| 🏛️ 한국사 | N.N/10 | ███████░░░ | 🟢 양호 |
| 🔬 과학 | N.N/10 | ██████░░░░ | 🟡 보통 |
| 🌍 지리 | N.N/10 | ████████░░ | 🟢 양호 |
| 🎨 예술과문화 | N.N/10 | █████░░░░░ | 🟡 보통 |
```

평가 기준 (반 평균):
| 반 평균 | 평가 |
|---------|------|
| 8.0 이상 | ✅ 우수 |
| 6.0-7.9 | 🟢 양호 |

| 2.0-3.9 | 🟠 미흡 |
| 2.0 미만 | 🔴 부진 |
