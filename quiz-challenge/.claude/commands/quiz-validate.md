# 퀴즈 최상급 표현 검증

src/data/questions.ts 파일에서 최상급 표현이 포함된 문제를 찾아 검증합니다.

## 검색 대상 표현
- 가장
- 최초
- 최대
- 최고
- 최소
- 최저
- 유일
- 처음

## 작업 순서

1. src/data/questions.ts 파일을 읽습니다.
2. 위 표현이 포함된 문제를 찾습니다.
3. 아래 형식으로 결과를 출력합니다:

### 출력 형식

| ID | 카테고리 | 문제 | 최상급 표현 | 기준 명시 여부 |
|----|----------|------|-------------|----------------|

4. 기준이 명시되지 않은 문제가 있다면 수정을 제안합니다.

## 검증 기준 (CLAUDE.md 참고)

- 정답이 하나뿐인가?
- 최상급 표현에 측정 기준이 있는가? (면적, 길이, 높이, 수심 등)
- 시간과 범위가 명확한가?
