# 실기기·스크린리더 점검표

자동 검사(`node --test`, `tools/check-screens.js`, axe 접근성 검사)로는 실제 기기의 터치·키보드 앱·소리를 볼 수 없다.
이 표는 사람이 실기기에서 한 번 훑는 순서다. 한 기기에 20~30분이면 끝난다. 결과는 기기·OS·브라우저·
스크린리더 버전과 함께 이슈로 남긴다(라벨 없음, 제목 «[점검] 기기 이름»).

## 준비

- 기기: iPhone(Safari), Android 휴대폰(Chrome), Windows PC(Chrome + NVDA), 가능하면 Mac(Safari + VoiceOver)
- 스크린리더 켜는 법
  - iOS VoiceOver: 설정 → 손쉬운 사용 → VoiceOver. 측면 버튼 세 번 누르기를 단축키로 켜 두면 편하다
  - Android TalkBack: 설정 → 접근성 → TalkBack. 볼륨 위·아래 키를 함께 3초 누르는 단축키를 켜 둔다
  - Windows NVDA: nvaccess.org에서 받는다. Ctrl+Alt+N으로 켠다
  - macOS VoiceOver: Cmd+F5
- 온라인 점검은 기기 두 대(또는 기기 한 대 + PC)가 필요하다. 한쪽이 방장, 다른 쪽이 참가자다
- 주소: https://perust.github.io/quiz-by-quiz/

## A. 터치만으로 (스크린리더 끔)

| # | 할 일 | 기대 |
| --- | --- | --- |
| A1 | 홈에서 스틱으로 캐릭터를 움직이고 «선택»으로 분야 칸을 고른다 | 스틱이 손가락을 따라오고, 선택을 버튼 안에서 뗄 때만 눌린다. 밖으로 빼고 떼면 취소된다 |
| A2 | 퀴즈에서 보기를 직접 누른다 / 스틱으로 바닥 칸에 서서 시간이 끝나게 둔다 | 직접 누르면 바로 답이 나간다. 서 있던 칸이 시간 끝에 답이 된다 |
| A3 | 휴대폰을 가로로 돌린다 | 퀴즈가 두 열(왼쪽 질문·보기, 오른쪽 바닥)이 되고 스틱·선택이 보기나 칸을 덮지 않는다 |
| A4 | 로비에서 방 코드 칸을 누르고 한글 자판으로 적는다 | «영문 자판으로 바꿔 주세요»가 뜬다. 적는 동안 스틱·선택이 사라지고 칸 밖을 누르면 돌아온다 |
| A5 | 대기실 채팅을 보낸다 | 키보드가 올라와도 입력칸과 마지막 대화 줄이 보인다. «/ · Esc» 같은 키보드 안내는 보이지 않는다 |
| A6 | 온라인 매치 중 앱을 바꿨다가 1분 안에 돌아온다 | 같은 판으로 돌아오고 «연결 끊김»으로 빠지지 않는다 |
| A7 | 결과 화면에서 «다시 하기»를 바로 누른다 | 기록이 자동으로 남는다(랭킹에 보인다) |

## B. 스크린리더

| # | 할 일 | 기대 |
| --- | --- | --- |
| B1 | 홈을 처음부터 끝까지 쓸어 넘긴다 | 닉네임·분야 다섯 칸(전체 이름)·온라인·전체 도전이 이름으로 읽힌다. 캐릭터 그림은 읽히지 않는다 |
| B2 | 분야를 골라 퀴즈를 연다 | 질문이 읽히고 문항 시간(«문항당 20초»)이 함께 읽힌다. 남은 시간은 1초마다 읽지 않는다 |
| B3 | 남은 5초가 될 때까지 기다린다 | «5초 남았어요»가 한 번만 읽힌다 |
| B4 | 보기 하나를 고른다 | 판정(정답/오답), 정답 줄, 해설이 한 번 읽히고 «다음 문제»로 초점이 간다. 같은 말이 두 번 읽히지 않는다 |
| B5 | 결과 화면에서 «틀린 문제 해설 보기»를 누른다 | 오답 풀이 제목으로 초점이 옮겨 가고 거기서부터 읽힌다 |
| B6 | 설정 대화상자를 연다 | 토글 이름(«소리», «움직임 줄이기»)과 켜짐·꺼짐이 따로 읽힌다(«소리 꺼짐, 눌리지 않음»처럼 겹치지 않는다). 닫으면 설정 버튼으로 돌아온다 |
| B7 | 온라인 대기실에서 상대가 들어오고 준비한다 | 입장 줄이 대화 로그로 읽히고, 시작 버튼 아래 상태 줄(«준비 2/2명…»)이 바뀔 때 읽힌다 |
| B8 | 온라인 매치 중 상대가 채팅을 보낸다 | 말한 사람 이름과 함께 한 번 읽힌다. 새 문제를 읽는 중이면 끝난 뒤에 읽힌다(끊지 않는다) |
| B9 | 온라인 매치에서 공개 카드가 뜬다 | 정답·내 답·점수판이 읽힌다 |
| B10 | 랭킹 화면 탭을 오간다 | 탭 이름과 선택 상태가 읽히고, 목록 범위(«이 브라우저에 저장된 내 기록») 안내가 읽힌다 |

## C. 키보드만 (Windows·Mac, 스크린리더 끄고 켜고 각각)

| # | 할 일 | 기대 |
| --- | --- | --- |
| C1 | Tab으로 홈의 버튼을 모두 지난다 | 초점 고리가 늘 보이고, 캐릭터의 발밑 고리와 동시에 두 개 보이지 않는다 |
| C2 | 방향키로 걷다가 Enter | 발밑의 버튼이 눌린다. 빈자리에서 Space는 페이지를 내린다 |
| C3 | 대기실에서 `/`로 채팅칸에 들어가고 Esc로 나온다 | 칸에서 나와도 화면은 그대로다(로비로 튕기지 않는다) |
| C4 | 퀴즈에서 숫자 1~4 | 그 보기가 답이 된다. 길게 눌러도 한 번만 |

## 결과 남기기

- 기대와 다르면 단계 번호(예: B8), 기기·OS·브라우저·스크린리더 버전, 실제로 들린 말이나 본 화면을 적는다
- 화면 녹화나 스크린샷이 있으면 붙인다. 닉네임·방 코드가 보이면 가린다
